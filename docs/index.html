Global results are weighted averages of different task mixes.

The global treatment result can be smaller than every fleet-level result because control and treatment do not contain the same proportions of each fleet. This is a Simpson's-paradox-style aggregation effect.

The Toolkit

Four methods, one product principle: compare like with like and show uncertainty.

CUPED

Compare every bucket against historical expectation.

Useful when hour, weekday, fleet, or load history predicts the metric.

Raw +18 min
Adjusted -2 min

CIs

Show the likely range, not only the point estimate.

A positive-looking estimate is weak if the interval crosses zero.

Estimate +1.2 min
CI +0.4 to +2.0

Adjusted Regression

Compare treatment and control inside similar conditions.

Protects fleet slices from hour, day, load, and volume imbalance.

Adjusted about -2

MLM

Pool information across fleets when some slices are small.

Powerful, but harder to explain. Keep it for an advanced version.

CUPED

Ask how each bucket performed versus history.

Raw comparisons can punish treatment for landing in harder hours. CUPED subtracts an expected baseline first, then compares treatment and control residuals.

Raw comparison

Control quiet hour: 23 min

Treatment dinner peak: 41 min

Treatment looks +18 min worse

CUPED view

Control: 23 - 22 baseline = +1 min
Treatment: 41 - 42 baseline = -1 min

Treatment looks about 2 min better

Confidence Intervals

Separate promising from conclusive.

A point estimate says what happened in the sample. A confidence interval shows the range still compatible with the data. For switchbacks, calculate it from fleet-hour or fleet-day buckets.

Conclusive example

Treatment improves O2D by +1.2 min; CI +0.4 to +2.0.

Less conclusive example

Treatment improves O2D by +1.2 min; CI -0.8 to +3.2.

Adjusted Regression

Compare treatment within similar hours and conditions.

Adjusted regression estimates treatment after accounting for hour of day, day of week, load factor, and volume. Inside one fleet, no fleet adjustment is needed because there is only one fleet.

MLM

Borrow strength when fleet samples are uneven.

Multilevel models estimate overall and fleet-specific effects in one hierarchy. The main user-facing idea is partial pooling: tiny samples should not get the same trust as large samples.

Fleet A 100 buckets
Observed -2 min; MLM estimate maybe -2 min.
Fleet B 100 buckets
Observed -1 min; MLM estimate maybe -1 min.
Fleet C 4 buckets
Observed -8 min; MLM estimate maybe -3 min.
Fleet D 4 buckets
Observed +5 min; MLM estimate maybe 0 min.

Rose squares are observed effects. Teal squares are the MLM estimates after partial pooling.
