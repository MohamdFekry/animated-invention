Lesson 1

Fleet mix can bend the global result.

Treatment can improve inside every fleet and still look less impressive globally. That happens when treatment has more tasks in an expensive fleet.

The puzzle

-44 fils globally, but -46 to -52 inside each fleet.

The global number is not the average of the fleet differences. It is a weighted average of fleet CPOs using each variant's task mix.

Plain English

The expensive fleet gets more volume.

Marina costs more in both control and treatment. If treatment handles more Marina tasks, treatment's global average is pulled upward even though treatment still improves Marina itself.

global CPO = fleet CPO x fleet task share
