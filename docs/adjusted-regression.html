Lesson 5

Adjusted regression asks a fairer comparison question.

If treatment happens more during dinner peak, raw averages may confuse “treatment is bad” with “dinner peak is hard.”

The simple idea

Compare quiet with quiet, and peak with peak.

Regression does that comparison in one model while also adjusting for things like hour, day, load factor, and volume.

Plain English

Raw averages mix together easy and hard hours.

Treatment can look worse if it has more peak-hour buckets. The adjusted view asks: within the same type of hour, did treatment help?

Try this

Set treatment peak share to 95%.

Raw gets much worse because treatment has mostly hard hours. The adjusted result remains close to the within-hour treatment effect.

When to use it

Use it after filtering or slicing.

Filters can accidentally make treatment and control less comparable. Regression helps protect against that remaining imbalance.

Product lesson

Show raw and adjusted together.

If they disagree, the page should explain which condition mix is causing the disagreement.
